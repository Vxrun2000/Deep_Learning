# Deep Learning from Scratch

Implementations of core deep-learning concepts developed during my **M.Sc. Computational Engineering** studies.

The repository follows a progression from fundamental numerical operations in **NumPy** to manually implemented neural networks, convolutional and recurrent architectures, and finally modular **PyTorch** training workflows.

The emphasis is on understanding the mathematics and computational mechanisms behind deep-learning models before using high-level frameworks.

## Learning Progression

```text id="9t5m6v"

        ↓

        ↓

        ↓
PyTorch training workflows
```
